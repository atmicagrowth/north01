# NORTH / 01 — Luxury Editorial Visual Guide

## Purpose

This guide defines the visual identity and art direction for NORTH / 01.

It is intentionally **visual-only**. It does not define product features, interactive behavior, technical implementation, or business logic.

Use it as the visual source of truth for the website.

---

## Visual business-model constraint

NORTH / 01 is presented as an online-only apparel brand. Visual direction should communicate a premium digital fashion house rather than a physical retail storefront.

Use visual language associated with campaigns, editorial commerce, remote delivery, digital discovery, and online brand identity. Do not introduce storefront exteriors, shop windows, POS counters, physical retail signage, store-location graphics, or in-store promotional scenes as default brand imagery.

This is a visual-direction rule only; it does not define product or technical behavior.

# 01 — Brand Character

The brand should read as a high-end fashion label first and a digital store second.

### Quiet Luxury

Confidence without visual noise. Nothing should feel promotional unless the design intentionally calls for it.

### Editorial

Think fashion magazine, campaign book, and gallery wall rather than a generic ecommerce template.

### Modern

The system should feel current without leaning on short-lived visual trends.

### Tactile

Textures, photography, typography, and spacing should suggest physical materials and premium objects.

### Structured

Strong alignment, measured grids, and repeatable spacing create discipline beneath expressive photography.

### Human

Avoid sterile perfection. Photography and copy should feel authored, intentional, and culturally aware.

## Visual Tension

Use large and small together:

- Oversized type with tiny metadata
- Full-bleed imagery with narrow text columns
- High-contrast black surfaces with soft bone typography
- Large whitespace beside compact utility elements

The contrast should feel deliberate, never chaotic.

---

# 02 — Color System

The palette is intentionally limited. The luxury comes from proportion, texture, and contrast—not from having many colors.

| Color | Hex | Role |
|---|---|---|
| **Obsidian** | `#0A0A0A` | Primary background |
| **Charcoal** | `#151515` | Primary surface |
| **Warm Black** | `#1D1C1A` | Elevated surface |
| **Bone** | `#F1EEE8` | Primary text |
| **Warm White** | `#FAF8F4` | Bright text / light surfaces |
| **Stone** | `#A9A39A` | Secondary text |
| **Muted Stone** | `#77726B` | Tertiary text |
| **Graphite** | `#33312D` | Rules / borders |
| **Soft Taupe** | `#C7B8A0` | Very limited accent |

## Color Rules

- Black and charcoal dominate the visual field.
- Bone and warm white carry the primary information hierarchy.
- Stone and muted stone are supporting colors, not headline colors.
- Soft taupe is a rare accent, not a general-purpose highlight.
- Borders should usually be low-contrast graphite rather than bright white.
- Avoid introducing additional saturated colors unless there is a strong brand reason.

---

# 03 — Typography

Typography is a primary brand element, not decoration.

## Display Typography

Use a refined, high-contrast serif for:

- Major campaign statements
- Collection titles
- Editorial headlines
- Large brand statements
- High-impact promotional moments

The exact font can change later; the visual role should remain consistent.

### Display example

**NORTH / 01**

### Character

- Elegant
- High contrast
- Fashion-oriented
- Slightly dramatic
- Never playful or cartoonish

---

## Sans-Serif System

Use a clean modern sans-serif for:

- Navigation
- Labels
- Product metadata
- Pricing
- Controls
- Supporting copy
- Utility information

### Character

- Neutral
- Precise
- Highly legible
- Contemporary
- Minimal

---

## Type Scale

| Level | Approx. Size | Use |
|---|---:|---|
| Display XL | 48–72px | Campaign statements / hero headlines |
| Display L | 36–52px | Collection / editorial headlines |
| Heading M | 24–34px | Section titles |
| Heading S | 16–20px | Subheadings |
| Body | 14–16px | Reading copy |
| Meta | 11–13px | Labels / utility / product details |
| Micro | 9–10px | Tiny metadata / utility |

## Typography Rules

- Prefer strong left alignment over default centered alignment.
- Use serif/sans contrast intentionally.
- Give large headlines room to breathe.
- Avoid excessive font-weight variation.
- Avoid overly rounded or playful typefaces.
- Avoid using display serif for dense UI or product metadata.
- Avoid making every section headline enormous.

---

# 04 — Layout & Grid

The system should feel spacious, exact, and editorial.

## Desktop

- Use a disciplined max-width grid.
- Prefer a 12-column grid for complex compositions.
- Maintain generous outer margins.
- Use asymmetry when it creates editorial tension.
- Align typography, imagery, and structural rules to shared grid anchors.

## Tablet

- Reduce column count rather than simply shrinking everything.
- Preserve visual hierarchy.
- Keep the same spacing language and typography relationship.

## Mobile

- Strong single-column rhythm.
- Occasional two-column moments for product/editorial layouts.
- Preserve the visual hierarchy of the desktop composition.
- Do not make mobile feel like a completely different brand.

## Grid Principles

- Consistent gutters
- Clear alignment
- Strong vertical rhythm
- Generous outer spacing
- Intentional asymmetry
- Controlled density

---

# 05 — Spacing Language

Spacing should communicate luxury through breathing room.

| Scale | Approx. Value | Use |
|---|---:|---|
| XS | 4–6px | Tight control spacing |
| S | 8–12px | Labels / small groups |
| M | 16–24px | Default component spacing |
| L | 32–48px | Section internals |
| XL | 64–96px | Section separation |
| XXL | 120–180px | Major editorial breathing room |

### Rules

- Small utility groups can be compact.
- Large editorial sections should have significant breathing room.
- Do not remove whitespace simply to fit more content.
- Avoid random spacing values that create visual drift.
- Reuse spacing relationships consistently.

---

# 06 — Component Styling

Components should look like parts of the same fashion system.

## Buttons

- Mostly rectangular or softly squared
- Thin borders
- Restrained fills
- Uppercase labels where appropriate
- Compact letter spacing
- Avoid oversized pill buttons as the default

## Inputs

- Dark surfaces
- Thin graphite borders
- Generous internal padding
- Quiet labels
- Clear focus states
- Minimal decoration

## Dividers

- 1px
- Low contrast
- Used to structure space
- Never used as decorative noise

## Cards

Use sparingly.

Product presentation should generally feel open rather than being boxed into repeated rounded containers.

## Badges

- Small
- Typographic
- Quiet
- Monochrome or very restrained

Avoid colorful sticker-like badges.

## Drawers / Dropdowns

- Solid charcoal surfaces
- Strong alignment
- Clear hierarchy
- Restrained motion
- Minimal shadowing

## Icons

- Thin line icons
- Consistent stroke weight
- Simple geometry
- Small visual footprint

Never use oversized decorative icons.

## Links

- Text-first
- Precise
- Often underlined or paired with a subtle rule
- Hover states should be subtle and controlled

---

# 07 — Product Presentation

Product imagery should dominate the visual space.

## Product image treatment

- Large image area
- Strong crop
- Consistent product photography
- Minimal surrounding UI
- Quiet typography beneath or beside imagery

## Product information

Product names and pricing should be visually quieter than the imagery.

Treat variant/color information as small, precise metadata.

Avoid turning every product into a floating rounded card.

---

# 08 — Imagery Direction

**No imagery is embedded in this guide.**

The following rules define the photography language to use when assets are added.

## Campaign Photography

- High-fashion editorial
- Strong silhouettes
- Controlled lighting
- Architectural or minimal environments
- Intentional crops
- Strong negative space

## Lifestyle Photography

- Human enough to feel authentic
- Composed enough to feel premium
- Avoid obvious stock-photo energy

## Product Photography

- Clean
- Consistent
- Accurate
- Neutral backgrounds when needed
- Editorial crops when appropriate

## Color Grading

Favor:

- Black
- Cream
- Stone
- Concrete
- Washed neutrals
- Restrained accents

Avoid highly saturated or overly artificial grading.

## Composition

Use negative space deliberately so typography can live beside or over imagery.

## Motion / Image Movement

When motion is used:

- Keep it slow
- Keep it subtle
- Prefer crossfades and gentle reveals
- Avoid exaggerated zooms
- Avoid distracting parallax
- Avoid motion that competes with the subject

## Core Rule

Photography can change dramatically from campaign to campaign, but typography, spacing, overlays, crop discipline, and color grading should keep the overall brand recognizable.

# 09 — Page-Level Art Direction

This section describes composition only.

## Home

- Hero-first composition
- Large campaign statement
- Editorial blocks alternating between image-led and typography-led sections
- Product areas should feel like interruptions in a fashion story, not the entire page
- Strong visual pacing from section to section

## Shop / Listing

- Quiet, spacious grid
- Photography does most of the work
- Controls stay compact and visually secondary
- The top of the page should feel calm and structured

## Product

- Large gallery dominates
- Product information is precise and narrow
- Typography and spacing create the premium feeling
- Avoid crowding the main product area

## Collection

- Campaign-led composition
- Large opening image or color field
- Restrained introduction
- Merchandise broken into visual chapters
- Strong separation between chapters without unnecessary boxes

## Lookbook / Editorial

- Magazine rhythm
- Large images
- Asymmetric whitespace
- Short text blocks
- Strong chapter titles
- Occasional full-bleed moments

## About

- More narrative and human
- Generous text width
- Documentary/editorial imagery
- Strong vertical pacing

## Account / Utility

- Simpler and calmer than marketing pages
- Same visual identity
- Less visual drama
- Utility should remain effortless and clear

# 10 — Responsive Visual Rules

The design should preserve hierarchy and mood across screen sizes.

## Priority

When space shrinks:

1. Preserve headline hierarchy.
2. Preserve imagery quality.
3. Preserve primary alignment.
4. Remove decorative details only after the above are protected.

## Mobile Typography

Reduce display sizes carefully.

Do not flatten the typography into generic mobile text.

## Image Crops

Use intentional mobile crops instead of simply squeezing desktop images into a smaller box.

## Whitespace

Reduce oversized spacing where necessary, but never remove the breathing room that creates the premium feeling.

## Mobile Navigation

- Quiet
- Monochrome
- Highly legible
- Minimal visual clutter

## Touch Targets

Controls should be comfortably tappable without becoming visually oversized.

## Density

Mobile can be denser than desktop, but should still feel deliberate and editorial.

---

# 11 — Visual Guardrails

## Do

- Use strong editorial photography with intentional crops.
- Keep backgrounds mostly dark and neutral.
- Use serif typography for emotion and sans-serif typography for utility.
- Let whitespace create luxury.
- Use alignment and repetition to create visual confidence.
- Keep controls understated and precise.
- Use motion sparingly and slowly.
- Keep product presentation visually open.
- Let a small number of strong visual moments carry the page.

## Avoid

- Excessive gradients
- Glow effects
- Glassmorphism
- Neon accents
- Rounded-card overload
- Oversized pill buttons everywhere
- Decorative elements competing with product imagery
- Excessive centered text
- Making every page look like the homepage
- Short-lived UI trends that weaken the fashion identity
- Excessive shadows
- Visually noisy dashboards
- Overly playful illustrations
- Generic "AI website" layouts

---

# 12 — Final Visual Test

A page is on-brand when it still looks unmistakably NORTH / 01 with the text removed.

The following should identify the brand by themselves:

- Palette
- Proportions
- Typography
- Spacing
- Imagery treatment
- Grid discipline
- Structural rhythm
- Component restraint

If a page feels like it could belong to any generic ecommerce template, it is not finished.
